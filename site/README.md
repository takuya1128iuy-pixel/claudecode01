# 比較推奨販売ルール改正ガイド

金融庁が 2026年8月28日に公表した「比較推奨販売」に関する意見募集資料をもとに、
乗合代理店の保険募集人・保険媒介業者向けに内容を整理した解説サイトです。

- `index.html` … 単一ファイルで完結する静的サイト（外部依存は Google Fonts のみ）

## 特徴

- **2つの読み方** … ヘッダーの「サクッと／じっくり」で表示を切り替え。選択は `localStorage` に保存されます。
  「サクッと」でも、各テーマの「＋ 詳しく読む」でそのセクションだけ展開できます。
- **テーマから飛べる** … トップのテーマカードと左サイドのテーマ一覧から該当セクションへジャンプ。
  スクロールに応じて現在地をハイライトします。
- **出典を明示** … 各テーマの末尾に、根拠となる資料名と該当条項（条・号・イロハ、監督指針の項番）を記載。
  末尾の「出典一覧」に資料01〜04へのリンクをまとめています。
- ライト／ダークテーマ、モバイル対応。

## 出典

- 資料01 金融庁 公表資料（意見募集）: https://www.fsa.go.jp/news/r8/hoken/20260828/01.pdf
- 資料02 保険業法施行規則及び金融サービス仲介業者等に関する内閣府令の一部を改正する内閣府令（案）新旧対照表
- 資料03 保険会社向けの総合的な監督指針（新旧対照表）
- 資料04 金融サービス仲介業者向けの総合的な監督指針 新旧対照表

本文の記載はすべて資料02〜04の新旧対照表に基づいています。資料01は作成環境からアクセスできなかったため、
意見募集の正式名称・募集期間等は記載していません。

## 確認方法

```bash
# 任意の静的サーバで
python3 -m http.server 8000 --directory site
# → http://localhost:8000/
```

ブラウザで `site/index.html` を直接開いても動作します。

## GitHub Pages について

現在 `.github/workflows/deploy.yml` は `claude/sake-tasting-app-demo-bbnia0` ブランチのみを
GitHub Pages に公開する設定です。このサイトを Pages で公開する場合は、公開ブランチの切り替え
（同一 Pages サイトを共有するため、既存デモとの調整）が必要です。
