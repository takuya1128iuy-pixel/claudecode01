# 比較推奨販売 実務ガイド

金融庁が 2026年8月28日に公表した「比較推奨販売」に関するパブリックコメント結果
（コメントの概要及びコメントに対する金融庁の考え方・全450ページ・759件）と新旧対照表をもとに、
乗合代理店の保険募集人・保険媒介業者向けに内容を整理した解説サイトです。

- `index.html` … 単一ファイルで完結する静的サイト（外部依存は Google Fonts のみ）
- `build/` … `index.html` を生成するスクリプトと本文データ

## 構成

| 部 | 内容 |
|---|---|
| 第1部 現場編 | 募集の4ステップ、推奨理由に使える言葉／使えない言葉、場面別Q&A 10本 |
| 第2部 条文編 | 内閣府令・監督指針の新旧対照 9本 |
| 第3部 資料編 | 資料01の分類とNo.の早見表、出典一覧 |

## 2つの読み方

ヘッダーの「サクッと／じっくり」で表示が切り替わります。選択は `localStorage` に保存されます。

- **サクッと** … 各セクションの結論（1〜3文）と「こうする／これはできない」だけ。条文の引用・新旧対照・
  金融庁の回答・出典の詳細は非表示。
- **じっくり** … 上記に加え、条文の引用、新旧対照表、金融庁の回答の全文、出典の内訳を表示。

「サクッと」のままでも、各セクションの「＋」ボタンでそのセクションだけ展開できます。

## ナビゲーション

- トップの「もくじ」カード、左サイドの一覧（デスクトップ）、上部のチップ列（モバイル）から各セクションへジャンプ
- スクロール位置に応じて現在地をハイライトし、モバイルではチップ列が自動追従
- ヘッダー上部に読了プログレスバー
- 施行日までの残日数を自動計算して表示

ライト／ダークテーマ、モバイル対応、`prefers-reduced-motion` 対応。

## 出典

- 資料01 コメントの概要及びコメントに対する金融庁の考え方（全450ページ・759件）: https://www.fsa.go.jp/news/r8/hoken/20260828/01.pdf
- 資料02 保険業法施行規則及び金融サービス仲介業者等に関する内閣府令の一部を改正する内閣府令 新旧対照表
- 資料03 保険会社向けの総合的な監督指針（新旧対照表）
- 資料04 金融サービス仲介業者向けの総合的な監督指針 新旧対照表

条文の解説は資料02〜04、「金融庁の考え方」は資料01からの引用です。引用に当たり括弧を全角に統一し、
長い回答は一部を省略しています。759件すべてを掲載しているわけではありません。
「募集の流れ」の4ステップと「言える理由、言えない理由」の分類は、複数の回答から編集部が整理したものです。

## ビルド

```bash
python3 site/build/build.py     # site/index.html を生成
```

## 確認方法

```bash
python3 -m http.server 8000 --directory site   # → http://localhost:8000/
```

ブラウザで `site/index.html` を直接開いても動作します。
