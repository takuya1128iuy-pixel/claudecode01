# 比較推奨販売 影響セルフチェック

10の質問に答えると、2026年8月28日に金融庁が公表した比較推奨販売の改正のうち、
回答した状況に関係する部分だけが表示される診断ツールです。

質問は募集現場で使う言葉で書いています（「事業報告書のどれに○をつけているか」のような
管理側の言い回しは、結果側のヒントに移しました）。

- `index.html` … 単一ファイルで完結する静的サイト（外部依存は Google Fonts のみ）

姉妹サイトの `../index.html`（比較推奨販売 実務ガイド）が改正の全体像を扱うのに対し、
こちらは「自分にどう関係するか」に絞り込みます。

| 1 | 立場（代理店法人／代理店個人／保険会社の募集人／金融サービス仲介業者） | 見る監督指針、事業報告書の様式 |

| 6 | 共同募集の有無 | 共同募集の論点 |

### 質問2は立場で変わります

| 立場 | 設問 |
|---|---|
| 保険代理店 | 委託を受けている保険会社は何社ですか（生保・損保・少短の合計） |
| 保険会社の募集人 | 勤務先の保険会社は、他の保険会社等の保険も取り扱っていますか |
| 金融サービス仲介業者 | 取り扱っている相手方保険会社等は何社ですか |

## 判定

- 24件のトピックに `when(answers, derived)` の条件をつけ、該当したものを重要度順（重要／要対応／確認／参考）に表示
- 13件の準備タスクにも同様の条件をつけ、該当分だけを個別化したチェックリストとして出力
- 矛盾検出（2種）
  - 代理店が「1社だけ」と答えつつ生保・損保の両方を扱う場合は、引受会社が別であることから
    乗合代理店に該当する可能性が高い旨を表示し、以降は乗合代理店として判定する（資料01 No.374・375）
  - 「何社か並べて説明するだけ」と答えつつ特定の1社を名指しで勧める場合は、それが推奨販売に
    あたる旨を表示する
- 保険会社の募集人は一律に対象外としない。規則227条の2第3項第4号の括弧書きが、他社の募集人にも
  なっている保険会社（「保険募集人保険会社等」）を「二以上の所属保険会社等を有する保険募集人」に
  含めているため、勤務先が他社商品も扱うなら対象として判定する。この場合の比較対象は
  「一以上の所属保険会社等の保険と、自社の保険」（資料02 第一条 規則227条の2第3項第4号 柱書・ロ）
- 質問5の回答で、条文の前段（選別して提示：概要＋基準や理由）と後段（特定の1本を推奨：加えて
  他契約がある旨＋説明の申し出）を切り分ける

回答とチェック状態は `localStorage` にのみ保存され、外部に送信されません。
結果は印刷できます（印刷時はナビゲーションを落とし、内容のみを出力）。

ライト／ダークテーマ、モバイル対応、`prefers-reduced-motion` 対応。

## 出典

すべて金融庁が2026年8月28日に公表した以下の資料に基づきます。

- 資料01 コメントの概要及びコメントに対する金融庁の考え方（全450ページ・759件）
- 資料02 保険業法施行規則及び金融サービス仲介業者等に関する内閣府令の一部を改正する内閣府令 新旧対照表
- 資料03 保険会社向けの総合的な監督指針（新旧対照表）
- 資料04 金融サービス仲介業者向けの総合的な監督指針 新旧対照表

判定の分岐、重要度の付け方、準備リストは、公表資料を読み解いて構成したものです。
原文にこの形の整理はありません。金融庁の公式見解ではなく、個別の事案について
法的な結論を示すものでもありません。
