# ✍️ かんじドリル

小学生が漢字を練習するためのアプリです。iPad / iPhone の Safari で「ホーム画面に追加」すると、アプリのように全画面で使えます。

公開URL: **https://takuya1128iuy-pixel.github.io/claudecode01/kanji/**

## できること

- **学年 → 回 → 出題** の3ステップ。プリントと同じように「第1回」「第2回」…と小分けで練習できます
- **3つの解答モード**
  - ✍️ **かきとり**: マスに指や Apple Pencil で書く → おてほんと見くらべて自分で丸つけ
  - 🔘 **4たくクイズ**: 例文の □ に入る漢字を4つから選ぶ（自動採点）
  - 🔤 **よみ**: 漢字の読みをひらがなで入力する（自動採点）
- **きょうのふくしゅう**: まちがえた漢字を覚えているかどうかに応じて、1日後・2日後・4日後…と自動で出しなおします（ライトナー方式）
- **きろく**: れんぞく学習日数、2週間のカレンダー、学年ごとの習得率、にがてな漢字

記録はブラウザの `localStorage` にだけ保存されます（サーバー送信なし）。

## iPad / iPhone で使う

1. Safari で上記URLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると全画面になります

- 手書きのマスは Apple Pencil に対応しています。ペンで書き始めたあとは、手のひらが画面に触れても線になりません（パームリジェクション）
- 拡大縮小は切ってあるので、書いている途中でページが動きません

## 収録している漢字（現状）

| 学年 | 収録 | 配当表の字数 |
| --- | --- | --- |
| 1年生 | 80字（第1〜8回） | 80字 |
| 4年生 | 24字（第1〜2回） | 202字 |
| 2・3・5・6年生 | 準備中 | — |

例文はすべてこのアプリのために書き下ろしたものです（既存のプリント教材の文章は使っていません）。学年の区切りは小学校学習指導要領の「学年別漢字配当表」に合わせています。

## データを足すには

`src/data/gradeN.ts` に `KanjiEntry` を並べるだけです。例文の `{}` で囲んだ部分が出題対象になり、そこから3モードぶんの問題が自動で作られます。

```ts
{
  char: "案", grade: 4, lesson: 1,
  on: ["アン"], kun: [], strokes: 10,
  items: [
    { word: "案内", reading: "あんない", sentence: "駅までの道を{案内}する。" },
  ],
}
```

追加したら `src/data/index.ts` の `ENTRIES` に読み込ませます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + ビルド
npm run lint
node scripts/make-icons.mjs   # PWA アイコンを作りなおす
```

## 技術構成

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- 手書きは Canvas + Pointer Events（外部ライブラリなし）
