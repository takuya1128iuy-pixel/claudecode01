# ✍️ かんじドリル

小学生が漢字を練習するためのアプリです。iPad / iPhone の Safari で「ホーム画面に追加」すると、アプリのように全画面で使えます。

公開URL: **https://takuya1128iuy-pixel.github.io/claudecode01/kanji/**

## できること

- **小学校で習う漢字 1026字を全部収録**（1年80・2年160・3年200・4年202・5年193・6年191）
  - 学年ごとに8〜18回に分かれていて、1回10〜12字。紙のドリルと同じ進み方
- **3つの解答モード**
  - ✍️ **かきとり**: マスに指や Apple Pencil で書く → おてほんと見くらべて自分で丸つけ
  - 🔘 **4たくクイズ**: 例文の □ に入る漢字を4つから選ぶ（自動採点）
  - 🔤 **よみ**: 漢字の読みをひらがなで入力する（自動採点）
- **テストモード（100点満点）**
  - 回ごとのテスト = 10問 × 10点、学年まとめテスト = 20問 × 5点
  - 100点は🌸はなまる、80点以上は💮、60点以上は⭕
  - 回ごとのベストスコアを記録して一覧に表示
- **レベル**: 練習1問正解で +10、まちがえても +2、テストは点数ぶん（100点はボーナス +50）。
  レベルが上がると「みならい → かけだし → かんじ好き → かんじ博士 → かんじ名人 → かんじマスター」と称号が変わります
- **ユーザー切り替え**: 名前とアイコンを登録して、きょうだいで別々に記録を残せます
- **きょうのふくしゅう**: まちがえた漢字を、1日後・2日後・4日後…と自動で出しなおします（ライトナー方式）
- **きろく**: れんぞく学習日数、2週間のカレンダー、テストの履歴、学年ごとの習得率、にがてな漢字

- **バックアップ**: 記録をファイル（JSON）に書き出し／読みこみ。機種変更や、iPad と iPhone で
  同じ記録を使いたいときに。読みこむときは、同じ人の記録は進んでいるほう（けいけんちが多いほう）を残します

記録はブラウザの `localStorage` にだけ保存されます（サーバー送信なし）。1問ごと・1テストごとに
自動保存され、次に開いたときは前回の人のホーム画面から始まります。起動時に
`navigator.storage.persist()` でブラウザに「このデータを消さないで」と申請しますが、
Safari の設定やデータ消去では失われるので、ときどきバックアップを取ってください。

## iPad / iPhone で使う

1. Safari で上記URLを開く
2. 共有ボタン（□に↑）→「ホーム画面に追加」
3. ホーム画面のアイコンから起動すると全画面になります

- 手書きのマスは Apple Pencil に対応しています。ペンで書き始めたあとは、手のひらが画面に触れても線になりません（パームリジェクション）
- 拡大縮小は切ってあるので、書いている途中でページが動きません

## データについて

| 種類 | 出どころ |
| --- | --- |
| 学年・配当順 | [学年別漢字配当表（平成29年告示＝現行）](https://github.com/fnshr/kyo-kan)（CC0 1.0） |
| 画数・音読み・訓読み | [KANJIDIC2 由来のデータ](https://github.com/davidluzgouveia/kanji-data)（KANJIDIC2 © 電子辞書研究開発グループ(EDRDG), CC BY-SA 4.0） |
| 語・例文 | すべてこのアプリのために書き下ろし |

学年・画数・読みは `scripts/build-base.mjs` で `src/data/base.generated.ts` に生成しています（生成物はコミット済みなので、ビルド時にネットワークは不要です）。

```bash
node scripts/build-base.mjs <kyoiku-kanji-2017.csv> <kanji.json>   # 基礎データの再生成
node scripts/check-items.mjs                                        # 例文データの検査
```

## 例文を足す・直すには

`src/data/items/gradeN.ts` を編集します。1行が漢字1字ぶんです。

```ts
案: [["案内", "あんない", "駅までの道を{案内}する。"]],
//   ↑出題する語  ↑読み      ↑例文（出題する語を {} で囲む）
```

`{}` の中身から、3モードぶんの問題が自動で作られます。編集したら `node scripts/check-items.mjs` で
「全字そろっているか」「語にその漢字が入っているか」「読みがひらがなか」を検査できます。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # 型チェック + ビルド
npm run lint
node scripts/make-icons.mjs   # PWA アイコンを作りなおす
```

## 技術構成

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- 手書きは Canvas + Pointer Events（外部ライブラリなし）
