# 家計の顧問FP — 年間顧問契約書ドラフト & LPデモ

「家計の顧問FP」サービス（年間顧問契約 年額50,000円＋個別サポート）の
顧客向け契約書ドラフトと、集客用ランディングページのデモです。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | LPデモ。単体のHTMLで、ブラウザで開くだけで動きます（料金見積りの簡易シミュレーター付き） |
| `contract/顧問契約書_ドラフト.docx` | 年間顧問契約書ドラフト（Word）。本文17条＋別表1・2＋別紙1・2 |
| `contract/contract.md` | 同じ内容のMarkdown版（レビュー・差分確認用） |
| `contract/build-contract.cjs` | 契約書の本文データと、docx / md を生成するスクリプト |

## 契約書に含まれるもの

- 本文（第1条〜第17条）: 目的、顧問業務、提供方法、顧問料、契約期間・自動更新、
  個別業務（オプション）、保険・NISA/iDeCo相談、業務範囲外・責任限定、協力義務、
  秘密保持、書類・データの取扱い、中途解約、解除、反社排除、損害賠償、変更、管轄
- 別表1: 年間顧問料に含まれる9項目（ライフプラン／資産状況／目標進捗／保険／資産運用／
  書類丸投げ／書類への対応案内／ふるさと納税／日常のお金相談）と実施時期
- 別表2: 個別業務の料金表（顧問顧客 vs ビジター）
- 別紙1: 重要事項（保険・金融商品の提案、IFA・保険募集人としての立場、手数料）
- 別紙2: スポット相談（ビジター）申込書 兼 同意書

## 契約書を再生成する

本文を直すときは `contract/build-contract.cjs` の中のデータを編集して、再生成します。

```bash
cd fp-advisory/contract
npm i --no-save docx   # 初回のみ。リポジトリの依存には含めていません
node build-contract.cjs
```

## 注意

- ドラフトです。`○○` `＿＿` `【 】` の箇所は事務所の実情に合わせて確定してください。
- 料金の税込／税別、中途解約時の返金（第12条）は選択が必要です。
- IFA（金融商品仲介業）・保険募集に関する表現は、所属金融機関の規程と関係法令に
  照らして確認し、最終版は弁護士等のリーガルチェックを受けてください。
- LPの事務所名・連絡先・お問い合わせフォームは仮のもので、送信処理はありません。
