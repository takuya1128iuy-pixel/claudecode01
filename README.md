# 秋冬カラー&素材ノート

アパレル販売の現場で、**接客中に色の合わせ方と素材の説明をすぐ引く**ためのスマホ用ノート。
2026/27年秋冬版。

売場では紙もPDFも開けないので、**3タップ以内で答えに届くこと**を他のどの機能より優先している。

## できること

- **カラー** — 今季29色。**まず暖色/寒色/中性で大きく分け、次に系統（ニュートラル・ベージュ&ブラウン・レッド…）で絞る**。色をタップすると、印象・面積比の目安・**合わせやすいベーシック色**・接客での一言が出る
- **手持ちの色から探す** — お客様が着ている色（黒・ネイビー・グレー・ベージュ・白・ブラウン・デニム）から、合う今季の色を逆に引く。接客中に一番使う導線
- **素材** — 秋冬26種。暖かさ・重さ・毛玉・**家庭で洗えるか**・しまい方に加えて、「毛玉が心配です」「洗えますか？」といった**よく聞かれる質問への答え**をそのまま持っている。売場でよく出るものから並ぶ
- **トレンド** — 今季のトレンド28項目を、**店頭 / キーワード / シルエット / アイテム / スタイリング / 柄 / カラー / 素材** で絞って読める。各項目に「何が起きているか」と「売場ではどう使うか」、そして**説明の前に出典**。あわせて今季のカラーテーマ、4つのカラーグループ、その年のメッセージカラー
- **参考** — 配色ルール8つ／洗濯表示（新JIS記号）／シルエット I・A・Y・X
- **今日の1枚** — 起動すると、その日の色・素材・配色ルールが1つずつ。隙間時間で読み切れる量
- **お気に入り** — よく聞かれるものに ☆ を付けておくと、ホームにまとまる
- **検索** — 「洗える」「毛玉」「くすみ」など、お客様の言葉で色と素材を横断して探せる

## 売場で使うための作り

- **片手・縦持ち前提**。主要ナビは画面下部、タップ領域は44px以上
- **オフラインで動く**。一度開けば、電波の弱いバックヤードや地下フロアでも開ける（Service Worker）
- **ダークモード対応**。暗い店内や夜の通勤で目に痛くない
- **色は必ず色名とカラーコードを併記**。色だけで意味を伝えない
- **端末フォントのみ**を使う（Webフォントを読みに行かないので、オフラインでも表示が崩れない）
- **トレンドの説明は、解説より先に出典を出す**。どこが言っていることなのかが分かってから読める
- お客様の個人情報を入力する欄は**作っていない**

## iPhone で使う

1. Safari でURLを開く
2. 下部の共有ボタン（□に↑）→「ホーム画面に追加」

ホーム画面から起動すると全画面になり、アドレスバーが消える。
お気に入りはその端末の中だけに保存され、外部には送信されない。

## データについて

データは3層に分けている（詳細は [`docs/apparel-fw2026-requirements.md`](docs/apparel-fw2026-requirements.md)）。

| 層 | 中身 | 出どころ |
| --- | --- | --- |
| **L1 不変知識** | 配色ルール・素材・洗濯表示・シルエット | 自前で執筆。毎年使えるので陳腐化しない |
| **L2 シーズン情報** | 今季のテーマ・キーワード・29色 | [JAFCA 2026/27年秋冬レディスウェアカラー](https://jafca.org/colortrend/2026-27awladies/) |
| **L2 シーズン情報** | その年のメッセージカラー | [JAFCA 2026年の色](https://jafca.org/colortrend/2026%e5%b9%b4%e3%81%ae%e8%89%b2%e3%81%af%e3%80%81%e5%bf%83%e6%ba%80%e3%81%a1%e3%82%8b%e3%83%8f%e3%83%bc%e3%83%88%e3%83%95%e3%82%a7%e3%83%ab%e3%83%88%ef%bd%a5%e3%83%94%e3%83%b3%e3%82%af/) |
| **L2 シーズン情報** | トレンド26項目（シルエット・アイテム・柄・カラー・素材） | FASHIONSNAP「2026年秋冬ウィメンズトレンド」[#01](https://www.fashionsnap.com/article/26aw-womens-trend-01/) / [#02](https://www.fashionsnap.com/article/26aw-womens-trend-02/) / [#03](https://www.fashionsnap.com/article/26aw-womens-trend-03/) |
| **L2 シーズン情報** | 店頭の立ち上がり傾向2項目 | [WWDJAPAN 2026-27年秋冬カテゴリー別リアルトレンド](https://www.wwdjapan.com/articles/2427788)（無料公開部分のみ） |
| **L3 市場実データ** | 実際に売られている色・素材の傾向 | 未実装（保留） |

全データに出典（`source`）を必須にしている。**出典を書けない情報は載せない。**

### 色の値の扱い

- 各色のHEXは、JAFCAが公開しているカラーカードから**実測した近似値**であり、JAFCAが定める色の規格値ではない。画面や照明で見え方が変わるので、実物の色は必ず商品で確認する
- 日本語の色名は**アプリ独自の呼称**。JAFCAは個別の色名を公表していないため、「JAFCAが名付けた色名」として説明しない
- 色の系統分け（暖色/寒色/中性・9系統）は、売場での呼び方に合わせたアプリ独自の分類。色相環の厳密な分類ではない

### トレンド情報の書き方

- 各項目の「何が起きているか」は、出典の内容を**自分の言葉でまとめたもの**。本文の転載や画像の複製はしていない
- 「売場では」は**アプリ独自の読み替え**であり、出典元の主張ではない。その旨をアプリ内にも明記している
- WWDJAPANの記事は**無料で読める範囲のみ**を参照している（以降は有料会員限定）

### まだ入っていないもの

コーディネート例。権利の問題がない写真が用意できていないため、載せていない。

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm run lint    # oxlint
npm run build   # 型検査（tsc -b）＋ 本番ビルド
```

データを直すのは `src/data/` の下だけでよい。型が付いているので、`npm run build` で書き間違いに気づける。

- `src/data/types.ts` — データモデル
- `src/data/colorHarmony.ts` — 配色ルール／ベーシック色
- `src/data/materials.ts` — 素材
- `src/data/careLabels.ts` — 洗濯表示
- `src/data/silhouettes.ts` — シルエット
- `src/data/seasons/fw2026.ts` — 2026/27年秋冬

シーズンが変わったら `src/data/seasons/` に追加して `src/data/index.ts` に並べる。過去シーズンも残す。

### 同じサイトに同居しているアプリ

GitHub Pages は1リポジトリにつき1サイトで、デプロイのたびにサイト全体が置き換わる。
そのためこのワークフローは、既存アプリのソースを置き場所のブランチから取得して
1サイトに組み立てている。

| パス | アプリ | ソース |
| --- | --- | --- |
| `/` | きき酒ノート | `claude/kanji-learning-app-jqnn9u` のルート |
| `/kanji/` | かんじドリル | 同ブランチの `kanji/` |
| `/fw/` | このアプリ | このブランチ |

> **注意**: `claude/kanji-learning-app-jqnn9u` ブランチに push すると、そちらの
> ワークフローが動いて `/fw/` を含まないサイトに置き換わる。3アプリを同時に扱うなら、
> どちらか一方のワークフローに寄せる必要がある。
