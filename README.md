# 🍶 きき酒ノート（デモ）

飲んだ日本酒を記録して、自分の好みの傾向を見つけるためのデモアプリです。

## できること

- **記録一覧**: これまで記録した日本酒をカード形式で一覧表示
- **記録を追加**:
  - 銘柄名・蔵元・種別・飲んだ日をテキストで入力
  - ラベル写真を撮影 / アップロードして保存
  - 写真から文字を読み取り（OCR）、認識結果を銘柄名の候補として利用可能
  - 甘辛・淡麗〜濃醇・香りの強さをスライダーで記録
  - 総合評価（★1〜5）、味わいタグ（複数選択・自由入力）、感想メモ
- **好みの傾向**: 記録データから、高評価銘柄の味わいプロファイル（レーダーチャート）やよく選ぶ味わいタグ（棒グラフ）を自動集計して表示

データはブラウザの `localStorage` にのみ保存されます（サーバー送信なし）。初回起動時はサンプルデータ3件が入っています。

## 技術構成

- React + TypeScript + Vite
- Tailwind CSS v4
- [tesseract.js](https://github.com/naptha/tesseract.js)（ブラウザ内OCR。初回実行時に言語データをネットワークから取得するため、オフライン環境では読み取りに失敗します。その場合も手入力で通常通り記録できます）
- [Recharts](https://recharts.org/)（グラフ表示）

## セットアップ

```bash
npm install
npm run dev
```

## ビルド
